# Лабораторная работа 4 — Многослойный персептрон / Lab 4 — Multilayer Perceptron

## Задание / Task

1. Взять любую известную выборку.
2. Построить многослойный персептрон с одним скрытым слоем и выходном слое зафиксировать функцию активации softmax.
3. Произвести обучение персептрона алгоритмом ADAM.
4. Сравнить обобщающую способность сети для 4 функций активации в скрытом слое сети: ReLU, sigmoid, bipolar sigmoid, GELU. Построить таблицу с результатами сравнения.

---

1. Take any well-known dataset.
2. Build a multilayer perceptron with one hidden layer and fix the softmax activation function on the output layer.
3. Train the perceptron using the ADAM algorithm.
4. Compare the generalization ability of the network for 4 activation functions in the hidden layer: ReLU, sigmoid, bipolar sigmoid, GELU. Build a comparison table with the results.
