# Лабораторная работа 3 — Скрытая модель Маркова

## Условие

Инициализировать скрытую модель Маркова (СММ) случайным образом под английский алфавит: **26 букв + 1 пробел** (всего 27 символов наблюдения).

### Заданные параметры

| # | Параметр | Описание |
|---|----------|----------|
| 0 | `n_states` | Число скрытых состояний |
| 1 | `seed` | Зерно генератора случайных чисел |

### Параметры модели

| Параметр | Обозначение | Размерность | Описание |
|----------|-------------|-------------|----------|
| Начальное распределение | π | `n_states` | Вероятность начала в каждом состоянии |
| Матрица переходов | A | `n_states × n_states` | Вероятности перехода между состояниями |
| Матрица эмиссий | B | `n_states × 27` | Вероятности наблюдения символа в каждом состоянии |

Все параметры инициализируются случайными значениями и нормализуются (сумма по строке = 1).

### Задача

1. Инициализировать СММ случайным образом с заданными параметрами.
2. Ввести несколько фраз на английском языке (строчные буквы + пробел).
3. Для каждой фразы вычислить **вероятность её воспроизведения** моделью с помощью **алгоритма прямого хода** (Forward algorithm).

### Алгоритм прямого хода (Rabiner scaling)

1. **Инициализация**: `α₁(i) = πᵢ · bᵢ(O₁)`
2. **Индукция**: `αₜ₊₁(j) = [Σᵢ αₜ(i) · aᵢⱼ] · bⱼ(Oₜ₊₁)`
3. **Масштабирование**: `cₜ = 1 / Σᵢ αₜ(i)`
4. **Результат**: `log P(O|λ) = −Σₜ log(cₜ)`
